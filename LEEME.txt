HERO STREET-TECH — Iván Nahüel Cristini
========================================

Archivos:
  index.html              → el hero (abrilo en el navegador)
  images/
    esfera-cromada.png    → objeto 3D (reemplazable)
    letra-I-cromada.png   → objeto 3D (reemplazable)
    aerosol-cromado.png   → objeto 3D (reemplazable)

REEMPLAZAR LOS OBJETOS 3D:
  Subí tus renders manteniendo el MISMO nombre de archivo
  (o cambiá la ruta en :root → --obj-sphere / --obj-letter / --obj-spray).
  Lo ideal: PNG con fondo transparente.

EDITAR:
  - Colores y fuentes: bloque :root arriba del <style>.
  - Paleta actual: negro (#0a0a0b) → blanco (#f4f4f5) → rojo (#e11122), cromado.
  - Textos: directamente en el HTML del <section class="hero">.

EFECTOS INCLUIDOS:
  - Parallax con el mouse (cada capa se mueve a distinta profundidad)
  - Objetos cromados flotando (animación floaty)
  - Cursor personalizado tipo mira (solo desktop)
  - Rejilla en perspectiva + glows + palabras graffiti de fondo
  - Menú mobile + reveal de entrada escalonado

Este es SOLO el hero (prototipo). El resto de las secciones
se construyen sobre esta misma base si te gusta la dirección.
